# 本棚機能 変更点・動作確認チェックリスト

## 主な変更点

### サーバー
- `better-sqlite3` → `@libsql/client` に移行（Turso/ローカル両対応）
- `books` テーブル追加（pdf_hash, title, filename, page_count, last_read_page）
- `/api/books` CRUD エンドポイント追加（GET / POST / PATCH / DELETE）
- `/api/books/import-local` — ローカル cache.db → Turso インポート

### クライアント
- `bookshelfStore.ts` — FileHandle・サムネイルを IndexedDB に保存
- `bookshelf.ts` — 本棚モーダル UI（追加・選択・再登録フロー）
- `main.ts` — 本棚からのPDF読み込み・ページ移動時の last_read_page 更新（500ms debounce）

### 設定
- `.env.example` に `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` を追記

## 動作確認観点

### 既存機能の回帰確認（優先）
- [ ] ファイル選択ダイアログからPDFを開ける
- [ ] ページ移動（←→キー、ボタン）が動く
- [ ] 翻訳ボタン（Tキー）で翻訳が表示される
- [ ] 2回目以降は「キャッシュ済み」バッジが出る
- [ ] 「ノートを保存」でMarkdownがダウンロードされる

### 本棚機能
- [ ] ツールバーに「本棚」ボタンが表示される
- [ ] 本棚を開くとモーダルが表示される（Escapeで閉じる）
- [ ] 「＋ 追加」→ PDFを選択 → カードにサムネイル付きで表示される
- [ ] カードをクリック → 許可ダイアログ → PDFが開く
- [ ] PDFを開いた後にページを移動すると、本棚カードの「p.XX / YY ページ」が更新される（リロード後に確認）
- [ ] ブラウザをリロードしても本棚のカード一覧が残る
- [ ] サムネイルがないカードにはプレースホルダー（📄）が表示される

### 再登録フロー
- [ ] 別ブラウザプロファイルや再起動でFileHandleが失効した場合に「再登録が必要」バッジが表示される

### Turso連携（設定した場合）
- [ ] `.env` に Turso 設定を追加して起動 → 翻訳・本棚が Turso に保存される
- [ ] 「cache.dbをインポート」ボタンでローカルデータが移行される
